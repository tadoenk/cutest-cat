A program that draws the cutest cat for make.fun's "Draw the cutest cat" bounty: a fluffy ginger kitten with big bright eyes, a head tilt and a yarn ball, written as one picture to /output/entry.png. An AI judge compares the pictures two at a time and picks the cuter cat.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
